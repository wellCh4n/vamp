## 1. What Strudel is

- The official JavaScript port of Tidal Cycles (the Haskell live-coding music language), making sound directly in the browser through Web Audio.
- Used for live coding, algorithmic composition, teaching, and as a MIDI/OSC sequencer.
- Online REPL: https://strudel.cc/
  - `Ctrl+Enter` runs/updates, `Ctrl+.` stops, `//` comments out a line.
- **License: AGPL-3.0**. Anything built with Strudel (including a "reimplementation" written after reading the source) must be released under a compatible open-source license, with source available. Keep this in mind for Vamp.

### Core concepts

- **Pattern**: a function of time. Query a time span and it returns the events (haps) in that span. Everything — `note()`, `s()`, `.lpf()` — returns a Pattern, so calls chain.
- **Cycle**: the basic unit of time. The default is **30 cpm (cycles per minute) = one cycle every 2 seconds**. Everything in a sequence is squeezed into a single cycle.
- **Longer sequences run faster**: in `"bd sd"` each event takes half a cycle; in `"bd sd hh cp"` each takes a quarter.
- Once an event fires, effect parameters are sampled only at that instant (except ADSR, pitch env, vib, tremolo, phaser and friends, which are continuous by nature). To make an LFO vary continuously, add events with `.segment(n)`.

## 2. Mini-notation (the little language inside quotes)

Text in **double quotes `"..."`** or **backticks `` `...` `` (which may span lines)** is parsed; **single quotes `'...'`** stay plain JS strings and are not parsed.

| Concept | Syntax | Example | Notes |
|---|---|---|---|
| Sequence | space | `"bd sd hh cp"` | splits one cycle evenly |
| Pick a sample | `:n` | `"hh:0 hh:1 hh:2"` | omitting it means `:0`; inside `s` you can also write `bd:1:0.5` (the third field is gain) |
| Rest | `~` or `-` | `"bd ~ hh -"` | |
| Sub-sequence | `[ ]` | `"bd [hh hh] sd"` | subdivides the slot it occupies; nests without limit |
| Speed up | `*n` | `"hh*4"`, `"[bd sd]*2"`, `"hh*1.5"` | fractions allowed |
| Slow down | `/n` | `"[c a f e]/2"` | plays out over n cycles |
| One per cycle | `< >` | `"<bd sd hh>"` | equivalent to `"[bd sd hh]/3"`; adding or removing elements does not change the tempo. Often combined with `*n`: `"<a b c d>*8"` |
| Parallel / chord | `,` | `"bd*2, hh*4"`, `"[c,e,g]"` | layers play together |
| Elongate | `@n` | `"c@3 eb"` | a weight, `@1` by default |
| Elongate (alternative) | `_` | `"c _ _ eb"` | each `_` stretches the previous event by one slot |
| Replicate | `!n` / `!` | `"c!2 e"`, `"c ! e"` | duplicates the event without speeding it up |
| Random drop | `?` / `?0.1` | `"hh*8?"`, `"hh*8?0.2"` | 50% chance of being dropped by default |
| Random choice | `\|` | `"bd \| hh \| sd"` | picks one branch per cycle |
| Euclidean rhythm | `(beats,segments,offset)` | `"bd(3,8)"`, `"bd(3,8,2)"` | 3 onsets spread evenly across 8 slots |
| Polymeter | `{ }` / `{ }%n` | `"{c eb g, c2 g2}%4"` | layers inside braces align by step rather than by cycle; `%n` sets steps per cycle |
| Grouping | `.` | `"bd sd . hh hh hh"` | the dot splits a sequence into equal "feet"; same as `"[bd sd] [hh hh hh]"` |
| Sample gain | the third `:` field inside `s()` | `"bd:0:0.3"` | |

Writing across lines:

```js
sound(`
[-  -  oh - ] [-  -  -  - ] [-  -  -  - ] [-  -  -  - ],
[hh hh -  - ] [hh -  hh - ] [hh -  hh - ] [hh -  hh - ],
[-  -  -  - ] [cp -  -  - ] [-  -  -  - ] [cp -  -  - ],
[bd -  -  - ] [-  -  -  bd] [-  -  bd - ] [-  -  -  bd]
`)
```

The function equivalents (mini-notation <-> function):

| mini | function |
|---|---|
| `"x*2"` | `.fast(2)` |
| `"x/2"` | `.slow(2)` |
| `"x(3,8)"` | `.euclid(3,8)` |
| `"x(3,8,1)"` | `.euclidRot(3,8,1)` |
| `"hh?"` | `.degrade()` / `.degradeBy(.5)` |
| `"a \| b"` | `chooseCycles("a","b")` |
| `"a b, c d"` | `stack("a b","c d")` |
| `"<a b>"` | `cat("a","b")` / `slowcat` |
| `"a b"` | `seq("a","b")` / `fastcat` |
| `"a@3 b"` | `stepcat([3,"a"],[1,"b"])` |

## 3. Sound (samples / synths)

### `s()` / `sound()`
- Select a sample or synth by name: `s("bd hh sd oh")`.
- Built-in sounds (no loading needed):
  - Drums: `bd` (kick), `sd` (snare), `rim`, `cp` (clap), `hh` (closed hat), `oh` (open hat), `cr` (crash), `rd` (ride), `ht` `mt` `lt` (toms), `sh` (shaker), `cb` (cowbell), `tb` (tambourine), `perc`, `misc`, `fx`
  - Miscellaneous samples: `casio insect wind jazz metal east crow space numbers num`
  - Piano: `piano`
  - GM instruments (VCSL / soundfont): `gm_electric_guitar_muted`, `gm_acoustic_bass`, `gm_synth_bass_1`, `gm_synth_strings_1`, `gm_xylophone`, `gm_voice_oohs`, `gm_blown_bottle`, `gm_accordion`, `gm_flute`, `gm_lead_6_voice`, … (the REPL's sounds panel lists them all)
  - Synth waveforms: `sine`, `sawtooth` (`saw`), `square`, `triangle` (`tri`), `supersaw`, noise `white` `pink` `brown` `crackle`, ZZFX `z_sawtooth z_tan z_noise z_sine z_square`, wavetables `wt_*`
- **`note()` without `s()` defaults to `triangle`.**
- Samples load lazily: the first trigger may be silent while the file is still downloading.

### `bank()`
- Pick a drum machine: `s("bd sd hh").bank("RolandTR909")`. Under the hood it joins the names into `RolandTR909_bd`.
- Common ones: `RolandTR808`, `RolandTR909`, `RolandTR707`, `RolandTR505`, `AkaiLinn`, `RhythmAce`, `ViscoSpaceDrum`, `CasioRZ1`, `RolandCompurhythm1000`.
- It can be patterned: `.bank("<RolandTR808 RolandTR909>")`.

### `n()`
- For samples: which sample to take (out-of-range values wrap): `n("0 1 [4 2] 3*2").s("jazz")`.
- With `.scale()` it is a scale degree; with `.voicing()` it is a voice index.

### Loading custom samples with `samples()`
```js
// 1. object + base URL
samples({
  bassdrum: 'bd/BT0AADA.wav',
  snaredrum: ['sd/rytm-01-classic.wav', 'sd/rytm-00-hard.wav'], // array -> selected with n
}, 'https://raw.githubusercontent.com/tidalcycles/Dirt-Samples/master/');

// 2. the URL of a strudel.json (the json may set a base with "_base")
samples('https://raw.githubusercontent.com/tidalcycles/Dirt-Samples/master/strudel.json')

// 3. github shorthand  github:<user>/<repo>/<branch> (branch defaults to main)
samples('github:tidalcycles/dirt-samples')

// 4. pitched samples (the closest one is chosen automatically)
samples({ moog: { g2: 'moog/004.wav', g3: 'moog/005.wav' } }, 'github:tidalcycles/dirt-samples')
note("g2 c3").s('moog')

// 5. local: npx @strudel/sampler  -> samples('http://localhost:5432/')
// 6. shabda (freesound search / TTS): samples('shabda:bass:4,hihat:4') / samples('shabda/speech:hello')
```
- `soundAlias('RolandTR808_bd', 'kick')` creates an alias.
- The CDN the official REPL loads by default (reusable in your own project): `piano.json`, `vcsl.json`, `tidal-drum-machines.json`, `uzu-drumkit.json`, `uzu-wavetables.json`, `mridangam.json` and `Dirt-Samples/` under `https://strudel.b-cdn.net/`.

### Synth parameters
- The waveform is chosen through `s()`; `.noise(0.2)` adds pink noise; `.density()` controls crackle.
- Additive synthesis: `.partials([1,0,0.3,0,0.1])`, `.phases([...])` (with `s("user")` to build a new waveform; `randL(n)` makes a random list).
- FM: `.fm(4)` (the modulation index, fmi), `.fmh(1.5)` (harmonic ratio), `.fmattack .fmdecay .fmsustain .fmenv("lin|exp")`.
- Vibrato: `.vib(4)` in Hz, `.vibmod(0.5)` in semitones; shorthand `.vib("4:.5")`.
- supersaw: `.unison(7)`, `.detune(.2)`, `.spread(.5)`.
- Wavetables: `samples('bubo:waveforms'); s('wt_flute')` — the `wt_` prefix loops automatically.
- ZZFX parameters: `zrand curve slide deltaSlide zmod zcrush zdelay pitchJump pitchJumpTime lfo tremolo`.

## 4. Pitch (notes)

- `note("48 52 55 59")` takes MIDI numbers (69 = A4 at 440 Hz; fractions give microtones).
- `note("c e g b")` takes letters (a–g, any case), `#` sharpens and `b` flattens: `"c# eb"`. Octaves: `"c2 e3 g4"`, and **omitting the octave means 3**.
- `freq("220 275 330 440")` gives frequencies directly.
- Chords: `note("[c,e,g]")` or `note("c,e,g")`.
- **Scales**: `n("0 2 4 6").scale("C:minor")` — the numbers are scale degrees (negative and out-of-range values shift octaves automatically). The spelling is `root[octave]:type`, with multi-word types joined by colons: `"A2:minor:pentatonic"`, `"C4:bebop:major"`. It can be patterned: `.scale("<C:major D:mixolydian>/4")`. Common ones: `major minor dorian mixolydian lydian pentatonic minor:pentatonic major:pentatonic blues`.
- Transposing: `.transpose(7)` or interval notation `.transpose("<1P -2M 4P 3m>")`; `.scaleTranspose(2)` moves within the scale.
- `.add(n)` works on notes too (converted to MIDI numbers internally): `note("c2 e3".add("<0 5 7>"))`.
- Chord symbols to voicings: `chord("<C^7 A7b13 Dm7 G7>").voicing()`, optionally with `.dict('ireal')`, `.anchor("c5")`, `.mode("below|above|duck|root")`, `.offset(1)`. `n("0 1 2 3").chord("<C Am F G>").voicing()` turns it into an arpeggio, and `"<C^7 Dm7>".rootNotes(2).note()` takes the root notes for a bass line.
- `.arp("0 [0,2] 1")` arpeggiates stacked chords.
- `.piano()` is a shortcut: piano sound plus automatic panning by pitch.

## 5. Audio effects

Every parameter accepts a number, a mini-notation string or a signal. Most support the `a:b:c` colon shorthand.

### Filters
| Function | Aliases | Notes |
|---|---|---|
| `lpf(freq)` | `cutoff`, `lp`, `ctf` | low-pass cutoff; in `"1000:10"` the second field is lpq |
| `lpq(q)` | `resonance` | low-pass resonance, 0–50 |
| `hpf(freq)` / `hpq` | `hp`, `hcutoff` / `hresonance` | high-pass |
| `bpf(freq)` / `bpq` | `bandf`, `bp` / `bandq` | band-pass |
| `ftype("12db\|ladder\|24db")` | | filter type |
| `vowel("a e i o u")` | | vowel formant filter; also `ae aa oe ue y uh un en an on` |
| Filter envelope | `lpattack/lpa lpdecay/lpd lpsustain/lps lprelease/lpr lpenv/lpe` (same for hp* and bp*) | `lpenv` is the depth |

### Envelopes
- `.attack(.1) .decay(.1) .sustain(.25) .release(.2)`, aliased `att dec sus rel`.
- Shorthand `.adsr(".1:.1:.5:.2")`.
- Pitch envelope: `.penv(12)` (semitones), `.pattack .pdecay .prelease .pcurve(0|1) .panchor`. A kick: `note("g1*4").s("sine").pdec(.5).penv(32).pcurve(1)`.

### Dynamics / space
| Function | Notes |
|---|---|
| `gain(x)` | volume (exponential); `"[.25 1]*4"` for accents |
| `velocity(x)` | 0–1, multiplied into gain |
| `postgain(x)` | gain applied after every effect |
| `compressor("thresh:ratio:knee:att:rel")` | compression |
| `pan(0..1)` | panning; accepts signals such as `sine` |
| `jux(fn)` | left channel untouched, fn applied to the right: `.jux(rev)` |
| `juxBy(0.5, fn)` | adjustable stereo width; `juxFlip` swaps the sides each cycle |
| `delay(level)` | delay amount 0–1; shorthand `"0.8:0.125:0.8"` = level:time:feedback |
| `delaytime(s)` / `delayfeedback(0..1)` | feedback >= 1 grows louder without end |
| `room(level)` | reverb amount; in `"0.9:4"` the second field is size |
| `roomsize(0..10)` `roomfade` `roomlp` `roomdim` | reverb details (changing them recomputes the impulse, so do not modulate them) |
| `dry(x)` | reverb dry/wet |
| `phaser(speed)` `phaserdepth phasercenter phasersweep` | phaser |
| `tremolo(hz)` / `tremolosync(cycles)` `tremolodepth tremoloskew` | tremolo (amplitude) |
| `orbit(n)` | the global effect bus. **One orbit shares a single delay/reverb**, so patterns that need different reverb settings must sit on different orbits |
| `duckorbit(n) duckattack duckdepth` | sidechain ducking (a kick ducking other orbits) |
| `xfade(patA, "0..1", patB)` | crossfade |

### Distortion / degradation
- `distort(amount)` (aliased `dist`, and `"8:.4"` adds postgain); `crush(1..16)` for bit crushing; `coarse(n)` for downsampling; `shape` is deprecated.

### Sample playback control
| Function | Notes |
|---|---|
| `speed(x)` | playback rate (changes pitch); negative values play backwards: `"<1 2 -1 -2>"` |
| `begin(0..1)` / `end(0..1)` | trim the start / end |
| `clip(x)` / `legato` | multiply the event duration by x, cutting anything beyond it; samples play in full by default, and `clip(1)` makes them follow the event length |
| `cut(group)` | mutual exclusion within a group (a closed hat cutting off an open one): `s("[oh hh]*4").cut(1)` |
| `loop(1)` `loopBegin` `loopEnd` | looping |
| `chop(n)` | cut into n pieces played in order (granular feel) |
| `striate(n)` | play the next slice of the sample each time |
| `slice(n, "0 1 2 3")` / `splice` | slice and rearrange; splice also changes the rate to fit the slot |
| `loopAt(cycles)` / `fit()` | fit the sample to n cycles / to the event length (for break loops) |
| `scrub("0.25:2")` | drag the playback position like tape |
| `stretch(x)` | change pitch without changing tempo |
| `hurry(x)` | fast and speed at once |

Signal chain order (each effect appears once; a later one overrides an earlier one): source -> gain/ADSR -> lpf -> hpf -> bpf -> vowel -> coarse -> crush -> distort -> tremolo -> compressor -> pan -> phaser -> postgain -> dry/delay/room -> orbit -> duck -> mixer.

## 6. Signals — continuous values for automation

- Ranged 0..1: `sine` `cosine` `saw` `tri` `square` `rand` `perlin` (smooth randomness)
- Ranged -1..1: `sine2 cosine2 saw2 tri2 square2 rand2`
- Discrete randomness: `irand(n)` for integers 0..n-1, `brand` for 0/1, `brandBy(p)`
- Sequences: `run(n)` = `"0 1 ... n-1"`; `binary(5)` / `binaryN(55532,16)` for binary rhythms; `randL(n)` for a random list
- Mouse: `mousex`, `mousey`
- Transforms: `.range(min,max)` (linear), `.rangex(min,max)` (exponential — use it for frequencies), `.range2` (for the -1..1 signals), `.segment(n)` to sample a continuous signal into n events per cycle, and `.slow(4)` to change the LFO rate.

```js
s("hh*16").gain(sine)
s("hh*16").lpf(saw.range(500, 2000))
note("c2*8").s("sawtooth").lpf(sine.range(100, 2000).slow(4))
n(sine.segment(16).range(0,15)).scale("C:minor")
n(irand(8)).struct("x x*2 x x*3").scale("C:minor")
```

## 7. Pattern transformations

### Time
| Function | Notes |
|---|---|
| `fast(n)` / `slow(n)` | the `*` and `/` operators; patternable as `.fast("<1 [2 4]>")`, and `.slow("0.5,1,1.5")` layers several rates at once |
| `early(t)` / `late(t)` | shift t cycles earlier / later |
| `rev()` | reverse within each cycle; `palindrome()` alternates forwards and backwards |
| `iter(n)` / `iterBack(n)` | move the starting point one slot forward / backward each cycle |
| `ply(n)` | repeat every event n times (`"<1 2 3>"`) |
| `segment(n)` | sample into n events per cycle |
| `euclid(k,n)` `euclidRot(k,n,r)` `euclidLegato` | Euclidean rhythms |
| `swingBy(x, n)` / `swing(n)` | swing (swing = swingBy(1/3, n)) |
| `linger(frac)` | repeat the first fraction to fill the cycle |
| `zoom(a,b)` | stretch just the a..b span across the whole cycle |
| `compress(a,b)` / `fastGap(n)` | squeeze into a span and leave the rest empty |
| `inside(n, fn)` / `outside(n, fn)` | apply a transform inside / outside an n-cycle frame |
| `chunk(n, fn)` / `chunkBack` / `fastChunk` | split into n chunks and apply fn to one of them per cycle, in turn |
| `ribbon(offset, cycles)` | loop a slice of time (handy for pinning random results) |
| `press()` / `pressBy(x)` | push events back by half a slot (a syncopated feel) |
| `brak()` | a breakbeat feel |
| `cpm(n)` | the tempo of a single pattern |

### Structure
| Function | Notes |
|---|---|
| `struct("x ~ x x")` | give content a rhythm with a boolean / `x` pattern: `note("c,e,g").struct("x ~ x*2")` |
| `mask("1 0 1 1")` | mask with 1/0 |
| `beat("0,4,8,11", 16)` | place onsets by sixteenth-note position |
| `invert()` | swap 1 and 0 |
| `euclid`, `shuffle(n)`, `scramble(n)` | cut into n chunks and rearrange randomly (shuffle uses each chunk once, scramble may repeat) |
| `arrange([4, patA], [2, patB])` | arrange patterns, each for a number of cycles |
| `stack(...)` / `cat(...)` / `seq(...)` / `polymeter(...)` / `stepcat([w,pat],...)` | combining |
| `silence` / `.hush()` | silence |
| `set(pat)` / `keep(pat)` | merge parameters (the later / the earlier one wins) |

### Conditionals
| Function | Notes |
|---|---|
| `every(n, fn)` = `firstOf(n, fn)` | apply fn on the first of every n cycles: `.every(4, x=>x.rev())` |
| `lastOf(n, fn)` | on the last of every n cycles |
| `when("<0 1>", fn)` | apply when the condition is true |
| `pick` / `pickmod` / `inhabit` / `squeeze` | choose from a list of patterns by index |

### Layering
| Function | Notes |
|---|---|
| `superimpose(fn)` | the original plus the result of fn |
| `layer(fn1, fn2, ...)` | only the results of the fns |
| `off(t, fn)` | copy, delay by t, apply fn: `.off(1/8, x=>x.add(7))`; nests |
| `echo(times, t, feedback)` | echo-style layering with decreasing volume |
| `echoWith(times, t, (p,i)=>...)` | a different transform each repeat |
| `jux(fn)` | see the effects section |

### Randomness
| Function | Notes |
|---|---|
| `degrade()` / `degradeBy(p)` / `undegrade` | drop events at random |
| `sometimes(fn)` = 50%, `sometimesBy(p, fn)`, `often` 75%, `rarely` 25%, `almostNever` 10%, `almostAlways` 90% | apply per event, at random |
| `someCycles(fn)` / `someCyclesBy(p, fn)` | at random, per cycle |
| `choose(a,b,c)` / `wchoose([a,10],[b,1])` / `chooseCycles(...)` | pick a value at random |

### Arithmetic
`add sub mul div round floor ceil range rangex range2`, for example `n("0 2 4".add("<0 3 4 0>")).scale("C:major")` and `"<1 1.5 2>".mul(150).freq()`.

### Visualization / debugging
`.color("cyan")` `.label("x")` `.log()` `.tag("id")` `._scope()` `._pianoroll()` `._punchcard()`.

## 8. Multiple tracks and tempo

```js
setcpm(90/4)   // 90 bpm in 4/4: one cycle = one bar; setcps(1) means one cycle per second

$: sound("bd*4, [~ <sd cp>]*2, [~ hh]*4").bank("RolandTR909")
$: note("<[c2 c3]*4 [bb1 bb2]*4>").sound("gm_synth_bass_1").lpf(800)
_$: n("0 2 4").scale("C:minor").s("piano")   // a leading _ mutes this track
```

- `$:` starts an independent track per line (REPL/transpiler sugar, equivalent to `stack(...)`). `name: pattern` works too.
- In plain code you can also write `stack(a, b, c)` or `a.stack(b)`.
- `hush()` stops everything.

### Full example (the end of the workshop)

```js
setcpm(60)
$: n("0 [2 4] <3 5> [~ <4 1>]".add("<0 [0,2,4]>"))
  .scale("C5:minor").sound("gm_xylophone").room(.4).delay(.125)
$: note("c2 [eb3,g3]".add("<0 <1 -1>>"))
  .adsr("[.1 0]:.2:[1 0]").sound("gm_acoustic_bass").room(.5)
$: n("0 1 [2 3] 2").sound("jazz").jux(rev)
```

```js
// In the style of the official examples: filter envelope + randomness + drums
note("[c eb g <f bb>](3,8,<0 1>)".sub(12))
  .s("<sawtooth>/64")
  .lpf(sine.range(300,2000).slow(16))
  .lpa(0.005).lpd(perlin.range(.02,.2)).lps(perlin.range(0,.5).slow(3))
  .lpq(sine.range(2,10).slow(32)).lpenv(perlin.range(1,8).slow(2))
  .release(.5).ftype('24db').room(1)
  .juxBy(.5,rev).sometimes(add(note(12)))
  .stack(s("bd*2").bank('RolandTR909'))
  .gain(.5).fast(2)
```

## 9. Using Strudel in your own project (the part that matters for Vamp)

### The options
| Approach | Package | Character |
|---|---|---|
| iframe | `<iframe src="https://strudel.cc/?<share-id>">` or `#<base64 code>` | simplest, with the official UI |
| `@strudel/embed` | `<strudel-repl><!-- code --></strudel-repl>` | an iframe wrapper |
| `@strudel/repl` | `<strudel-editor><!-- code --></strudel-editor>` | embeds the official CodeMirror editor, no iframe, version can be pinned |
| **`@strudel/web`** | `initStrudel()` + `.play()` / `evaluate()` | **the one to use when building your own UI** (recommended for Vamp) |
| Fine-grained npm packages | `@strudel/core` `@strudel/mini` `@strudel/webaudio` `@strudel/transpiler` `@strudel/tonal` `@strudel/soundfonts` `@strudel/codemirror` … | needs a bundler such as Vite |

### Using `@strudel/web` (version 1.3.0 at the time of writing)

```html
<script src="https://unpkg.com/@strudel/web@1.3.0"></script>
<button id="play">play</button><button id="stop">stop</button>
<script>
  initStrudel({
    prebake: () => samples('github:tidalcycles/dirt-samples'),  // no external samples are loaded by default!
  });
  play.onclick = () => note('<c a f e>(3,8)').jux(rev).play();
  stop.onclick = () => hush();
</script>
```

```js
// npm / Vite
import { initStrudel, evaluate, hush, samples } from '@strudel/web';
await initStrudel({ prebake: () => samples('github:tidalcycles/dirt-samples') });
await evaluate('note("c a f e").jux(rev)');        // code as a string -> transpiled -> played (the second argument is autoplay=true)
hush();                                            // stop
```

Key points:
- After `initStrudel()` every function is on the global scope; it returns a promise that resolves once initialization finishes. It calls `initAudioOnFirstClick()` internally, and **browser autoplay policy still requires a user click first**.
- Only synth sounds are registered by default (`registerSynthSounds`); **samples must be loaded yourself inside `prebake`**. To match the official REPL, load `https://strudel.b-cdn.net/tidal-drum-machines.json`, `piano.json`, `vcsl.json` and friends (see section 3).
- `evaluate(code)` behaves exactly like the REPL (double quotes are mini-notation, `$:` is supported). Writing plain JS, you cannot call `.slow(2)` on a string directly — use `m("1 2 3").slow(2)` or wrap it in a control function such as `n("1 2 3")`. `miniAllStrings` is on by default, which treats every string as mini-notation.
- The remaining `initStrudel` options pass through to `webaudioRepl` -> `repl()`. Available callbacks:
  - `onToggle(started)` for the play/stop state
  - `beforeEval({code})` / `afterEval({code, pattern, meta})` / `onEvalError(err)`
  - `editPattern(pat => pat)` to post-process every pattern that is set (adding a global effect, say)
  - `onUpdateState(state)` (with `started`, `error`, `pattern`, `code`)
  - `sync: true` to schedule across browser tabs (SharedWorker)
  - `audioContext` for a custom AudioContext
- The object `initStrudel()` resolves to is the repl itself: `{ scheduler, evaluate, evaluateBlock, start, stop, pause, toggle, setCps, setPattern, setCode, state }`. `scheduler.cps` is the current tempo and `scheduler.now()` the current time; `setcpm(n)` / `setcps(n)` change the tempo from inside the code.
- Every event (hap) can carry a callback through `pattern.onTrigger((hap, currentTime, cps, targetTime) => ...)`, for visuals or lighting. `hap.value` is the parameter object (note, s, gain, …) and `hap.whole.begin/end` are its times.
- To highlight the code position currently playing, source locations are available in `meta` and `hap.context.locations` (this is how the official editor does it).
- Sample URLs must be reachable cross-origin (CORS).

## 10. Notes for Vamp

- The minimum viable architecture: Vite + `@strudel/web`, one textarea (or `@strudel/codemirror`) plus play/stop and `evaluate()`. Load the official CDN's drum machines and piano in `prebake`, and every workshop example runs.
- For AI-generated music, Strudel code is already prompt-friendly text and `evaluate()` runs it as is; `onEvalError` can feed errors back for the model to fix.
- Use `onToggle` / `onTrigger` for visuals (punchcard and pianoroll come from the official `@strudel/draw`).
- Remember the AGPL: the project has to be open source.
