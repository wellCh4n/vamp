# 和弦与和弦进行

规则一句话：**4 或 8 小节一轮的进行，每小节 1 个和弦，用 `chord("<...>")` 写，其他声部都跟着它走。**

## Strudel 里的写法

```js
const prog = "<C Am F G>"                       // 每小节一个和弦；"<C@2 F G>" 让 C 占两小节
$: chord(prog).voicing().s("gm_epiano1")         // 自动配置音，声部连接平滑
$: chord(prog).voicing().anchor("c5").mode("below")   // 限制配置音都在 c5 以下
$: chord(prog).rootNotes(2).note().s("gm_acoustic_bass") // bass 走根音，八度 2
$: n("0 1 2 3").chord(prog).voicing()                    // 拆成琶音：0 1 2 3 是配置音的第几个
$: chord(prog).voicing().arp("0 [0,2] 1 2")              // 另一种琶音写法
```

- 一小节两个和弦：`"<[C G] [Am F]>"`。别再密了，和弦换得太快旋律跟不上。
- 和弦符号：`C` 大三，`Cm` 小三，`C7` 属七，`C^7` 大七，`Cm7` 小七，`Cm7b5` 半减，`Csus`、`Cadd9`、`C6`、`C9`。爵士味用七和弦，流行 / 摇滚用三和弦，电子 / lofi 用 `m7`、`^7`、`add9`。
- 三和弦按功能：**主（T）** I、vi、iii 稳定；**下属（S）** IV、ii 离开；**属（D）** V、vii° 紧张、想回 I。进行的基本形状就是 T → S → D → T。

## 按曲风的常用进行（直接抄）

写成 C 大调 / A 小调，换调时把每个和弦按同样的距离移。

| 曲风 | 进行 | 说明 |
|---|---|---|
| 流行 / 万能 | `<C G Am F>` | I–V–vi–IV，最常用 |
| 流行（忧郁） | `<Am F C G>` | vi–IV–I–V |
| 抒情 / 民谣 | `<C Am F G>` | I–vi–IV–V，50 年代进行 |
| 卡农 | `<C G Am Em F C F G>` | 8 小节 |
| 爵士 | `<Dm7 G7 C^7 C^7>` | ii–V–I，用七和弦 |
| 爵士（小调） | `<Dm7b5 G7 Cm7 Cm7>` | ii°–V–i |
| 蓝调（12 小节） | `<C7 C7 C7 C7 F7 F7 C7 C7 G7 F7 C7 G7>` | 全部属七 |
| lofi / neo-soul | `<C^7 Am7 Dm7 G7>` 或 `<F^7 Em7 Dm7 C^7>` | 大七、小七，慢速 |
| house / 电子 | `<Am F C G>` 或 `<Am Am F G>` | 少量和弦，靠音色变化 |
| deep house | `<Am7 Dm7>` | 两个和弦来回 |
| 摇滚 | `<C F G F>` 或 `<Am C G D>` | 三和弦，力量感 |
| 西班牙 / 异域 | `<Am G F E>` | 安达卢西亚进行 |
| 电影 / 史诗 | `<Am F C G>` 慢速 或 `<Am Em F C>` | 加弦乐 pad |
| 中国风 | 见 `music-theory/chinese-modes.md` | 五声，和弦少用三音 |

## 和弦音对照（旋律强拍该落的度数）

以 C 大调、`scale("C:major")` 的度数计：

| 和弦 | 和弦音的度数 | 避免在强拍出现的度数 |
|---|---|---|
| C | 0 2 4 | 3 |
| Dm | 1 3 5 | 0 |
| Em | 2 4 6 | 3 |
| F | 3 5 0 | 2、6 |
| G | 4 6 1 | 0（除非是 G7 想回 C） |
| Am | 5 0 2 | 6 |

规则：旋律每小节第一个音和每拍第一个音尽量是和弦音；"避免"列的音只能作弱拍经过音，不能拉长。

## 让和弦有动感

- 节奏化：`chord(prog).voicing().struct("x ~ x x ~ x ~ x")` 让和弦按节奏型触发，而不是每小节一个长音。
- 每小节换配置：`.voicing()` 已经自动做平滑连接；想要跳跃感用 `.anchor("<c4 e4>")`。
- 加装饰：`sometimesBy(.3, x => x.add(note(12)))` 偶尔翻高八度；`.off(1/8, x => x.add(note(7)))` 加延迟五度。
- 段落对比：主段用三和弦，副歌换七和弦或 add9；或者 intro 只放 bass 和鼓，和弦在第二段才进。

## 常见错误

- 和弦一小节换四个：太密，旋律跟不上，听感杂乱。
- 和弦和 bass 各写各的：bass 必须从同一个 `prog` 用 `.rootNotes()` 派生，否则会撞。
- 进行的最后一个和弦是 I：一轮结束在主和弦会"停住"，循环回开头就没有推动力。让最后一个是 V 或 IV（`<C Am F G>` 而不是 `<G F Am C>`）。
- 小调曲子用了大调的 V（大三和弦）却没回到主：小调里 V 常用 `E7`（和声小调）以增强解决感，`<Am F Dm E7>`。
