# 调与音阶

规则一句话：**整首曲子用一个 `scale` 字符串，所有旋律和 bass 都用 `n()` 写度数**，这样永远不会出调外音。

## Strudel 里的写法

```js
const key = "D:minor"
$: n("0 2 4 7").scale(key)                // 度数从 0 开始：0 = 主音，2 = 三音，4 = 五音，7 = 高八度主音
$: n("0 2 4 7").scale(key).add(note(12))  // 整体升八度（用 note 加半音）
$: n("0 2 4".add("<0 -3>")).scale(key)    // 度数上加减：换到别的音级，仍在调内
```

- 度数可以是负数（往下走）和超过 7 的数（往上跨八度）。
- `.scale()` 里的根音可以带八度：`"D3:minor"`，默认是 3。
- `.transpose(n)` 是按半音移，会出调；`.scaleTranspose(n)` 是按度数移，不会出调。想移调整首曲子改 `key` 的根音即可。
- `note("c e g")` 手写音名只在确定音都在调内时用（比如和弦音）。混着写很容易错，尽量统一用度数。

## 常用音阶及其色彩

| 名字（Strudel 写法） | 色彩 | 适合 |
|---|---|---|
| `major` | 明亮、稳定 | 流行、儿歌、欢快 |
| `minor` | 忧郁、柔和 | 流行抒情、电子、lofi |
| `major:pentatonic` | 干净、中国风 / 民谣 | 中国风、ambient、lofi、任何"不会出错"的旋律 |
| `minor:pentatonic` | 摇滚 / 布鲁斯味 | 摇滚、funk、hip hop、电子 |
| `dorian` | 小调但不那么悲，有点爵士 | funk、house、爵士、电影感 |
| `mixolydian` | 大调但带一点摇滚 / 民谣的粗糙 | 摇滚、funk、蓝调摇滚 |
| `lydian` | 飘、梦幻 | 电影配乐、ambient |
| `phrygian` | 暗、西班牙 / 中东味 | techno、金属、异域 |
| `blues` | 布鲁斯 | 布鲁斯、爵士即兴 |

五声音阶（pentatonic）只有 5 个音，随便怎么走都不会撞出难听的小二度，是最安全的选择。七声音阶里第 3 和第 6 度（大调的 F、B 这一对）容易和和弦冲突，放弱拍。

## 大调和小调的关系

- 关系大小调共享同一组音：C 大调 = A 小调，G 大调 = E 小调。`C:major` 和 `A:minor` 的 `n("0")` 不同（C 与 A），但音的集合一样。
- 想让同一段旋律变忧郁：把 `key` 从 `"C:major"` 改成 `"C:minor"`（同主音小调），旋律度数不用改。

## 度数与和弦的对应（大调）

| 度数 n | 音（C 大调） | 上面能配的和弦 | 功能 |
|---|---|---|---|
| 0 | C | C（I） | 主，最稳 |
| 1 | D | Dm（ii） | 下属 |
| 2 | E | Em（iii） | 主的替代 |
| 3 | F | F（IV） | 下属 |
| 4 | G | G（V） | 属，想回主 |
| 5 | A | Am（vi） | 主的替代，小调色彩 |
| 6 | B | Bm7b5（vii°） | 属的替代，少用 |

写旋律时，当前小节和弦的"和弦音"就是根音、三音、五音的度数：C 和弦 = 0/2/4，Am = 5/0/2，F = 3/5/0，G = 4/6/1。强拍落这些，其他度数当经过音。

## 转调（进阶，一般不需要）

- 最简单：段落之间整体 `.scaleTranspose(2)` 或把 `key` 换成上方五度（C → G）。
- 电子 / 流行常见的"升 key"：最后一段把 `key` 根音升半音或全音，其他不变。
- 转调只放在段落边界（`arrange` 的分段处），段落中间不要换。
